# Weekly Meal Planner

A free website that helps people plan their meals for the week and builds one shopping list for them automatically.

## What it does
- Add a meal to any day of the week, with its ingredients.
- All ingredients are combined into one shopping list (repeats show as "×2").
- Tick items off while shopping.
- Everything is saved on the visitor's own device, so no sign-up is needed.

## How the code is organised
- `index.html`: what's on the page (the form, the week, the list).
- `style.css`: how it looks (colours, spacing, phone-friendly layout).
- `app.js`: how it works (adding meals, building the list, saving).

To try it, open `index.html` in any browser.
